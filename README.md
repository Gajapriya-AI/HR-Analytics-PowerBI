# HR Analytics Dashboard – Power BI

## Project Overview

This project is an HR Analytics Dashboard developed using Power BI to analyze employee data and generate meaningful HR insights.

The dashboard helps analyze employee demographics, job roles, salary ranges, business travel, education fields, and employee trends.

## Objectives

- Analyze employee workforce data
- Understand employee distribution
- Analyze job roles
- Analyze salary ranges
- Analyze business travel patterns
- Analyze employee education fields
- Generate meaningful HR insights

## Tools & Technologies

- Power BI
- Power Query
- DAX
- Excel / CSV

## Dashboard Features

- Total Employee KPI
- Employee Job Role Analysis
- Salary Range Analysis
- Business Travel Analysis
- Education Field Analysis
- Age Group Analysis
- Department and Job Role Filtering
